# Browser acceptance suites

Phase 01: `pnpm test:e2e:auth` runs actual Chromium, independent contexts/tabs, API/worker/Vite, Mongo/Redis/Mailpit and unique isolated test DB cleanup. Build first; install matching Chromium with `PLAYWRIGHT_BROWSERS_PATH` set to workspace `.cache/ms-playwright`. Ports 3000/3002/5173 must be free. Tests do not reuse your running dev server. Evidence: docs/phase-01-evidence.md. Phase 02: `pnpm test:e2e:conversations` runs the real inbox/direct/group/role/removal/block journey with three independent Chromium users, local email verification and desktop/mobile captures. Evidence: docs/phase-02-evidence.md. Run the suites sequentially because they own the same local server ports. Offline/attachment/call/a11y suites remain planned in their owning phases.

Phase 03: `pnpm test:e2e:messaging` proves real two-user text/reply storage, cross-user polling, a committed response dropped before the browser sees it, stable-ID retry without duplicates, reload persistence, worker readiness/metrics and desktop/mobile captures. Tests use isolated real DB/broker namespaces and cleanup. Run all browser scripts sequentially and outside the outbox suite's Rabbit outage window.
